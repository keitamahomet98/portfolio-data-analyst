# portfolio-data-analyst

Portfolio statique (HTML/CSS) compatible GitHub Pages.

## Déploiement GitHub Pages
- Branch: `main`
- Folder: `/ (root)`

## Arborescence
- `index.html` : page d'accueil
- `styles.css` : styles globaux
- `projects/` : pages projet détaillées
- `assets/reports/` : rapports PDF / HTML exportés
- `assets/img/` : images (favicon, captures)
- `notebooks/` : notebooks `.ipynb`
- `data/` : jeux de données (optionnel)

## Ajouter un projet
1. Créer `projects/<slug>.html`
2. Ajouter une carte dans `index.html` section `#projets`
3. Déposer rapport dans `assets/reports/`
4. Ajouter notebook dans `notebooks/` et lier le fichier GitHub
